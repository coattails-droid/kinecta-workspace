# Brainstorms

Creative idea dumps from the **graphite-brainstorm** GitHub Action.

Each run writes a new Markdown file named like `YYYY-MM-DDTHHMMZ-<topic-slug>.md`.
Trigger it from the Actions tab → **graphite-brainstorm** → Run workflow (optional topic).

Ideas are oriented around the Seeded Geometries NFT collection (hash-driven geometric art, traits, rarity, motion).
