Seeded Geometries

A prototype of hash-driven generative art. Each piece is rendered from a single 64-character token hash: fixed slices of the hash choose the coarse traits (grid system, palette, density, accent), while domain-separated sub-seeds feed independent random streams for all micro-detail. Same hash → same piece, forever, anywhere. No two mints share a seed.

js/seed.js holds the seed architecture, js/traits.js the trait / rarity logic, js/artwork.js the fused geometric system (triangle field under linear grid).

Demo hashes are deterministic stand-ins. A production deployment derives the token hash from the mint blockhash instead. Animation loops seamlessly: every motion is periodic in the loop phase, so the last frame flows into the first.
